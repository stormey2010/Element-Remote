Element Remote

Control your ETC Eos console over your local network with a direct, native iOS app.

Install on this device

Ad Hoc installation is available only on devices registered for this release.

Install steps

  1. Open this page in Safari on your iPhone or iPad.
  2. Tap Install and confirm the iOS prompt.
  3. Open Element Remote after iOS finishes installing it.

This is an Ad Hoc build. Your device must be registered with the developer before installation. The app connects directly to your console on the local Wi-Fi network.
