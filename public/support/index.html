Support

Element Remote Support
Contact support@elementremote.xyz for help.

To connect: join a network that can reach your lighting console, enable OSC RX and TX on the console, then open Settings > Add console and enter its IP. Start with TCP port 3032 and Packet Length framing. Saved profiles can be edited with the pencil button.

If search does not find the console, add it by IP. Wi-Fi client isolation, different subnets and custom ports may prevent automatic discovery. Allow Local Network access for Element Remote in iOS Settings.

To explore without hardware: open Settings, scroll to the bottom and enable Test Mode. The sample show does not load your console’s show file or simulate every Eos feature.

For a useful support request, include your app version, console model/software, connection protocol and a description of the problem. Do not send passwords or access tokens.
